# Safar Pakistan

A 13-page travel guide to Pakistan, built with HTML and CSS only.

Author: Mohsin Ali Mohsin, roll number BSE-23F-202

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a new public repository and upload every file in this folder to the main branch.
2. Open Settings, then Pages. Under Build and deployment choose Deploy from a branch, select `main` and `/ (root)`, then Save.
3. After a minute the site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
